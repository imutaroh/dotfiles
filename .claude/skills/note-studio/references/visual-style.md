## 共通スタイルブロック（プロンプトに毎回そのまま貼る）

```
【スタイル・厳守】上質でミニマルな線画インフォグラフィック。背景 #fafbfc。線と文字は墨紺 #1a2330 の細い均一な線画、補助の小さな文字は #5b6572。強調・矢印のアクセントにだけシアン #00add8。薄い面パネルは #f0f3f6、罫線 #e3e8ed。影・グラデーション禁止、角丸ごく小さく、余白広め、フラットで精密。日本語はモダンなゴシック体。キャラクター・マスコット・手描き感禁止。
```

内容指定の末尾に必ず「**文字は上記のみ**」を付ける（余計なラベルの湧きを防ぐ）。

## 1. アイキャッチカード

線画インフォグラフィックをアイキャッチにすると技術ブログの顔になる。**タイポグラフィ主体のカード**にする（zenn-studio の章扉カードの型を転用）。

```
【レイアウト】上質でミニマルなタイポグラフィ主体のカード（16:9）。イラスト・人物禁止。
- 中央に大きくタイトル「◯◯」、その下に小さくサブタイトル「◯◯」
- 下部に横並びのキーワードタグ3〜4個（シアンの細枠の小カード）: 「◯◯」「◯◯」「◯◯」
- タグの下に細いシアンの水平ライン
- 文字は上記のみ
```

- **16:9 で生成する**。note は横長画像の上下をトリムして表示するので、**文字要素は中央に寄せ、上下端に置かない**
- サブタイトルにカギ括弧が含まれるときは「⚠️先頭と末尾に余計なカギ括弧を足さない」を明記（二重カギ括弧事故の実績あり）

## 2. 頭の中の図解

note の本文図は概念のフローチャートではなく、**書き手の頭の中で起きたこと**を図にする。効く型:

| 型 | 中身 |
|---|---|
| 感情の時系列 | 横軸に出来事、縦軸に気分。折れ線1本＋各点に短いラベル |
| もつれ → ほどけ | 左に絡まった線の塊、右に整理された数本の線。中央に転機のラベル |
| ビフォー / アフター | 2分割。同じ構図で「前」と「後」を並べる |
| 選択肢の分岐 | 中央から2〜3本の矢印。選ばなかった道も描く |
| 頭の中の内訳 | 円や箱の面積で「何が何割を占めていたか」 |

### 捏造ガード（最重要）

**図の要素は本文に実際に書かれた記述だけから作る。** 図を成立させるために感情の段階・出来事・数字を足したくなるが、それは「実体験にない描写の追加」そのものになる。足したくなったら図をやめるか、本文側に `【要確認】` を付けて確認を取る。

## codex 生成コマンド

```bash
cd "/Users/imutaakihiro/repos/imutaakihiro/ObsidianImus/Private/AI workspace" && codex exec --sandbox workspace-write "image_generation ツールで16:9の画像を1枚生成し、images/<名前>.png に保存してください。

【スタイル・厳守】（↑の共通ブロック）

【内容】（レイアウトを具体的に。ラベル文言は「」で正確に指定）" 2>&1 | tail -2
```

- **必ず `cd <ディレクトリ> &&` を付ける**（cwd リセットで保存先がズレた実績あり）
- `run_in_background: true` で並列（同時5本程度まで。1枚2〜3分）
- 命名: アイキャッチ `nt-<slug>-eyecatch.png` / 本文図 `nt-<slug>-<概念>.png`
- 本文からの参照は `![要旨](images/xxx.png)`

## 検品基準（全数、Read で画像を開いて確認）

1. **日本語の描画崩れ**（誤字・欠け・存在しない字形）
2. **スタイル逸脱**（指定外の色・影・グラデーション・マスコット・手描き感）
3. **本文との整合**: 図が本文の比喩・主張と矛盾していないか
4. **本文に無い出来事・感情・数字を描いていないか**（note 固有・最重要）
5. 指定していないラベルの湧き・余計なカギ括弧
6. アイキャッチは上下がトリムされても意味が通るか

不合格は同じプロンプトに「⚠️〜は絶対に描かない」を足して上書き再生成する。

## プロセスの原則: 見本1枚 → 承認 → 量産

スタイルに関わる生成は、まず1枚だけ作って見せ、承認を得てから残りを量産する。

**この方針が破綻する条件**: note のタイムラインは写真的・感情的なサムネが並ぶ場所なので、ミニマル線画は埋もれるか浮くかのどちらか。ブランド統一（imutaro.com / Zenn / note が同じ顔）を優先した選択であることを忘れない。クリック率が明らかに落ちたら、アイキャッチだけ別路線に切り替える判断を提案する。
