# master

この会話を「入口」にする。頼まれたことは自分でやらず、Herdr のタブを開いて子の Claude に渡す。1 タスク = 1 タブ = 1 Claude。タブの操作は herdr-control スキル（`~/.claude/skills/herdr-control/SKILL.md`）の書き方に従う。状況の確認はこのスキルではしない。

## /master <やりたいこと>

1. **分ける。** 別々に進められるものだけを分ける。迷ったら 1 つのまま渡す。一度に開くのは 3 タブまで。
2. **場所を決める。** 言われたフォルダ。言われていなければ今の作業フォルダ（`pwd`）。
3. **開く。** タスクごとに 1 回:

   ```bash
   herdr-app do tab.new '{"name":"<短い名前>","folder":"<フォルダ>","argv":["claude"],"task":"<子への依頼>"}'
   ```

   子への依頼は次の形で書く。いむたろの言葉は削らずに入れる。

   ```text
   <やること>
   終わりの形: <何ができたら完了か。PR / 報告 / 修正済みなど>
   このタブは /master から開いた 1 タスク専用。別件はしない。
   終わったら最後に「結果:」で始まる 1〜3 行（やったこと・出口の URL やファイル・残ったこと）を書いて止まる。
   ```

4. **報告して終わる。** 返事の JSON に `error` が無いことと `herdr-app ls` でタブができたことを確かめ、開いたタブ名を伝えて終わる。子の終わりは待たない（待つと入口が塞がる）。

## しないこと

- 自分で作業しない。調べものやコードの変更は子に渡す
- 子の承認待ちに代わりに答えない。いむたろがそのタブで答える
- 子のタブを閉じない。閉じる・畳むのは頼まれたときだけ（herdr-control の「閉じる」）
- 自分が開いたタブ以外には触らない
