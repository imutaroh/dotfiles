## 共通スタイルブロック（本文図 16:9・プロンプトに毎回そのまま貼る）

```
【スタイル・厳守】上質でミニマルな線画インフォグラフィック。背景 #fafbfc。線と文字は墨紺 #1a2330 の細い均一な線画、補助の小さな文字は #5b6572。強調・矢印のアクセントにだけシアン #00add8。薄い面パネルは #f0f3f6、罫線 #e3e8ed。影・グラデーション禁止、角丸ごく小さく、余白広め、フラットで精密。日本語はモダンなゴシック体。キャラクター・マスコット・手描き感禁止。
```

内容指定の末尾に必ず「**文字は上記のみ**」を付ける（余計なラベルの湧きを防ぐ）。

## codex 生成コマンド（画像生成の正規ルート）

```bash
cd /Users/imutaakihiro/repos/imutaakihiro/ObsidianImus/Studio/zenn-claude-guide && codex exec --sandbox workspace-write "image_generation ツールで16:9の図解画像を1枚生成し、images/<名前>.png に保存してください。

【スタイル・厳守】（↑の共通ブロック）

【内容】（レイアウトを具体的に。ラベル文言は「」で正確に指定）" 2>&1 | tail -2
```

- **必ず `cd <リポ> &&` を付ける**（cwd リセットで保存先がズレた実績あり）
- `run_in_background: true` で並列（同時5本程度まで。1枚2〜3分）
- 命名: 記事 `ar-<slug>-<概念>.png` / 本 `<本の略称>-<章>-<概念>.png` / 章扉 `hd-<本の略称>-<章>.png`

## 章扉カード（本の各章の先頭用）

```
【レイアウト】上質でミニマルなタイポグラフィ主体の章扉カード（16:9）。イラスト・人物禁止。
- 上部に小さく「第 N 章」（数字だけシアン）
- 中央に大きくタイトル「◯◯」、その下にサブタイトル「◯◯」
- 下部に横並びのキーワードタグ3〜5個（シアンの細枠の小カード）: 「◯◯」「◯◯」「◯◯」
- タグの下に細いシアンの水平ライン
- 文字は上記のみ
```

- サブタイトルにカギ括弧が含まれるときは「⚠️先頭と末尾に余計なカギ括弧を足さない」を明記（二重カギ括弧事故の実績あり）
- 挿入位置: frontmatter 直後・`:::message` の上

## カバー（本の表紙）

- 縦長 2:3（1024×1536）で生成 → **必ず `sips -z 1050 700 <path> --out <path>` で縮小**（Zenn のカバー上限は 1MB。生成直後は超える）
- 構成: 上部にシリーズ名（小）→ 中央に大きな線画モチーフ1つ → 下部に冊名（大）＋一言 → 最下部にシアンの帯

## 検品基準（全数、Read で画像を開いて確認）

1. **日本語の描画崩れ**（誤字・欠け・存在しない字形）
2. **スタイル逸脱**（指定外の色・影・グラデーション・マスコット・手描き感）
3. **本文との整合**: 図が本文の比喩・主張と矛盾していないか（実例: 「机に引き出しはない」という本文比喩に対し、図の机に引き出しが描かれて再生成になった）
4. 指定していないラベルの湧き・余計なカギ括弧

不合格は同じプロンプトに「⚠️〜は絶対に描かない」を足して上書き再生成する。

## プロセスの原則: 見本1枚 → 承認 → 量産

スタイルに関わる生成は、まず1枚だけ作ってご主人様に見せ、承認を得てから残りを量産する。トーンマナーの好みは言語化より**参照URL（imutaro.com）を先に渡してもらう**方が速い。
