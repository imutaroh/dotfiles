# verify

完了と言う前に、自分で確認コマンドを実行し、その出力を見せる。実行していない確認は、してないと言う。

## このリポジトリ（dotfiles）

リポジトリ直下の CLAUDE.md「作業の進め方と確認」と同じものを実行する。Codex の 2 つはリンク先を見るので `~/dotfiles` で実行する。worktree からだと必ず NG になる。

```bash
./sync-settings.sh --check
python3 setup-codex-skills.py --check
bash .codex/scripts/check-parity.sh --quick
```

シェルを変えたときは `shellcheck` もかける。

## ほかのリポジトリ

そのリポジトリの CLAUDE.md、README、パッケージのスクリプトに書いてある確認を実行する。書いて無ければ、変更した言語のテストか lint を 1 つ選んで実行する。dbt のプロジェクトなら `dbt build`。見当たらなければ、見当たらないと言う。記憶で「通った」と書かない。

## 見せ方

- 実行したコマンド
- 終了コードと、成功か失敗か分かる出力
- 実行しなかった確認と、その理由

失敗した確認があれば、完了にしない。直すか、残っていることを先に書く。
