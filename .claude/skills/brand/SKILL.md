# brand

見た目と読みやすさの決まりの正本は、Obsidian Vault の `~/repos/imutaroh/ObsidianImus/Studio/Brand/` にある。このスキルは入口だけを持つ。色の値や規則はここに写さない（Brand を直すたびにずれるため）。

## 手順

1. `~/repos/imutaroh/ObsidianImus/Studio/Brand/workflow.md` を読み、最初の分岐で系統（見た目の種類）を決める。指定が無ければ、同じファイルの「アーティファクト作って」と頼まれたときの節に従う
2. その節が指すファイルのうち、作るものに要るものを読む。どのファイルに何があるかは、同じフォルダの `README.md` の表にある
3. 読むページ（Artifact・hview のページ）なら、同じフォルダの `readability.md` も読む。冒頭の置き方・図にするもの・数字と用語の説明・文の書き方はそこにある
4. 読んだ決まりで作る。見本やトークンの CSS があれば、値を打ち直さずにそれを写す
5. 選んだ系統の検品の手順を通してから見せる。読むページは `readability.md` の検品も通す

## ほかのスキルとの関係

- Brand が決めるのは見た目（色・文字・図の型）と、読むページの中身の書き方。Artifact は `artifact-design` スキルが求めるページの作りを、hview のページは `hview` スキルの制約を、そのまま守る
- 食い違ったら、ページが正しく映るための制約を先に守り、その中で Brand に寄せる。寄せられなかった点は、見せるときに一言添える

## しないこと

- `Studio/Brand/` の中身は、頼まれない限り書き換えない
- Vault が無い、またはファイルが読めないときは、記憶で色や文字を決めない。読めなかったことを伝えてから、既定の見た目で作る
